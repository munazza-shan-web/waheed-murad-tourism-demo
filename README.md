# Waheed Murad Tourism & Transportation ✈️

A responsive tourism and transportation website concept for exploring UAE tours, activities, and private transfers.

## ✨ Features
- Responsive website design
- UAE tours and transportation services
- WhatsApp enquiry integration
- Booking request form
- English and Arabic language toggle

## 🛠️ Technologies
- HTML5
- CSS3
- JavaScript
- SVG

## 🌐 Live Demo
[View Website](https://munazza-shan-web.github.io/waheed-murad-tourism-demo/)

## 🚀 Run Locally
1. Clone this repository.
2. Open `index.html` in your browser.
