# Waheed Murad Tourism & Transportation — Website Demo

A responsive, multi-page static website demo designed for GitHub Pages.

## Included
- Custom logo files: `assets/logo.svg` and `assets/logo-mark.svg`
- Homepage and service directory
- Dedicated pages for:
  - Dubai Desert Safari
  - Dubai City Tour
  - Abu Dhabi City Tour
  - Land Cruiser Rental
  - Chauffeur Services
  - Airport Transfers
  - Yacht Rental
  - Dinner Cruise
  - Jet Ski
  - Quad Bike
  - Corporate Transportation
- About, contact/booking, privacy and 404 pages
- Floating WhatsApp button and WhatsApp booking enquiry form
- English/Arabic direction toggle for key interface elements (translation is partial demo text; full Arabic copy needs professional review)
- Responsive mobile navigation
- SEO title and meta description on each page

## Before sharing with the client
1. Verify the WhatsApp number and email in `assets/site.js`, all HTML pages, and page footer.
2. Replace demo photography with properly licensed client-approved imagery.
3. Add real pricing, inclusions, cancellation policy, terms, and service availability.
4. Connect Google Analytics using the client's real Measurement ID after approval/consent setup.
5. Configure Google Business Profile, Search Console, advertising pixels, conversion tracking and privacy notices separately.
6. Connect a backend/CRM or booking platform if enquiries must be stored. Current forms open WhatsApp and do not save data.
7. Review the Arabic translation and right-to-left layout before production.
8. Add sitemap.xml and robots.txt after the final production URL is confirmed.

## Publish with GitHub Pages
1. Create a public repository on GitHub, for example `waheed-murad-tourism-demo`.
2. Upload all files and folders in this ZIP (keep the `assets` folder structure).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish. Your URL will look like:
   `https://YOUR-USERNAME.github.io/waheed-murad-tourism-demo/`
7. Test the homepage, every service link, mobile menu, date form and WhatsApp link.

## Demo limitations
- No payment gateway, live availability, booking database or admin dashboard.
- No guaranteed bookings, SEO rankings or advertising results.
- Google Analytics is not configured until the owner's ID is supplied.
- Contact form opens WhatsApp; it does not send email or persist customer data.
- Image URLs and Google Fonts require internet access.
